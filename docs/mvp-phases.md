# MVP Delivery Phases

## Phase 0 - foundation
- clean web app shell
- Docker + PostgreSQL
- Prisma schema
- architecture documentation

## Phase 1 - account and workspace
- login / logout
- first user bootstrap
- one gym per account
- protected dashboard

## Phase 2 - planning inputs
- employees CRUD
- areas CRUD
- opening hours
- employee qualifications
- vacations and fixed times
- core constraint settings

## Phase 3 - schedule generation
- create planning period
- generate weekly plan
- show assigned shifts
- show open/unfilled shifts clearly
- save generation result

## Phase 4 - review and editing
- manual assignment changes
- validation messages
- publish/finalize plan

## Phase 5 - scale and polish
- monthly planning
- reporting/export
- more roles and permissions
- fairness analytics
- production hardening
